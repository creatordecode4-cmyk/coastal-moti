# Coastal Moti: The Lost Pearl

An original 3D action-adventure browser game set on the Konkan coast. Works on phones and PCs.

**Play:** https://creatordecode4-cmyk.github.io/coastal-moti/

The game lives in the [`coastal-moti/`](coastal-moti/) folder (see its README for controls, structure and rules).
Every push to `main` that changes that folder republishes it with GitHub Pages
(`.github/workflows/deploy.yml`). Asset and code licences: [`coastal-moti/licenses/ASSETS.md`](coastal-moti/licenses/ASSETS.md).
